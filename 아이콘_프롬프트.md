# 디그리스 아이콘 — ChatGPT 이미지 프롬프트

## 사용법
1. ChatGPT 새 채팅을 열고 **① 스타일 프롬프트**를 먼저 보냅니다. (그림체 통일용, 한 번만)
2. 그다음 아래 표의 **프롬프트**를 하나씩 보냅니다. 한 번에 하나씩 만드는 게 결과가 좋아요.
3. 마음에 들면 **② 줄이기 프롬프트**를 보내서 32x32 PNG로 받습니다.
4. 파일 이름은 표의 `파일명`대로 저장 → ItemsAdder에 아이템으로 등록 → `icons.yml`에 연결 (맨 아래 참고)

같은 채팅방에서 계속 만들면 그림체가 비슷하게 유지돼요. 채팅방이 길어져서 그림체가 달라지면 새 채팅에서 ① 부터 다시.

---

## ① 스타일 프롬프트 (처음에 한 번)
```
I'm making a set of GUI icons for a Minecraft server (medieval fantasy nation-war theme).
For every icon I ask for from now on, follow this style exactly:
- Minecraft-style pixel art inventory icon, drawn on a 32x32 pixel grid
- crisp square pixels, no anti-aliasing, no blur, no gradients
- 1-pixel dark outline around the object, soft top-left lighting, 3–4 shades per color
- single object, centered, filling about 80% of the canvas
- fully transparent background, no shadow on the ground
- no text, no letters, no numbers
- rich but limited palette, consistent with the previous icons in this chat
Reply "OK" and wait for my first icon.
```

## ② 줄이기 프롬프트 (그림이 마음에 들 때마다)
```
Now resize this image to exactly 32x32 pixels using nearest-neighbor (no smoothing),
keep the background transparent, and give me the PNG file named [파일명].
```
`[파일명]` 자리에 표의 파일명을 넣으세요.

## icons.yml 연결 예시
ItemsAdder 네임스페이스를 `digriss`, 아이템 ID를 파일명에서 `.png` 뺀 이름으로 등록했다면:

```yaml
menu.국가: digriss:icon_nation
nation.info: digriss:icon_nation
menu.연합: digriss:icon_alliance
nation.alliance: digriss:icon_alliance
alliance.allied: digriss:icon_alliance
common.back: digriss:icon_back
common.close: digriss:icon_close
common.cancel: digriss:icon_close
# ... (표의 "쓰는 곳"에 적힌 키마다 한 줄씩)
```
저장 후 게임에서 `/아이콘 리로드`.

아이콘 PNG를 다 만들면 폴더째 알려주세요. ItemsAdder 아이템 설정 파일(yml)과 icons.yml 전체를 한 번에 만들어 드릴게요.
